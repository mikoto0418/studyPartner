### P0 强制全屏偶发失效

- [x] T1 定位「全程全屏作答」偶发不触发 / 误触发
  - 现象：客户实测全屏不好使，有时不触发、有时乱触发

  - 相关：web 端 `useAntiCheat` / `enterFullscreen` 无超时兜底；发布项「要求全程全屏作答」

  - 验收：双端多次进入作答页，全屏稳定触发；退出 / 切页仍正常记录违规事件

  - **已修复**：统一前缀全屏 API 读写、请求加 1.5s 超时、去掉 `navigationUI:'hide'`、
    删掉 `startTracking` 里那次无手势的二次请求、
    自动交卷门槛保持「累计退出 3 次」（曾误改成「连续」并在回到全屏时清零，
    导致学生「退出→恢复→再退出」时计数永远为 1、拦截完全失效，已回退并改正文案）、
    补挂 `webkitfullscreenchange`。**现场复现（学生端）**：走「进不去全屏」这条失败路径时
    不再假成功、不再卡死（按钮可重试）、不误弹遮罩；自动化浏览器会拒绝真实全屏请求，
    所以「成功进入全屏」的正向路径仍需人工在真实浏览器确认。
