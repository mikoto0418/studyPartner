# 教师监考与代码查看

监考中心选择试卷后，每 5 秒刷新作答状态和行为计数。窗口在后台、正在批改或请求失败时暂停自动刷新；失败会显示提示并保留已读取数据，可手动重试。

每位已开始作答的学生都有“查看代码”入口，不必等交卷。只读抽屉按试卷全部题目展示实际语言、服务器保存的代码、服务器记录更新时间和判题明细；没保存的题目显示空态。代码抽屉手动刷新，避免选区和阅读位置被轮询打断。

“服务器已保存草稿”不是最终提交，自测也不是交卷。教师看不到学生浏览器尚未同步的代码；服务器记录更新时间来自答案记录 updated_at，判分也会更新，不能当作精确的最后键入时间。已交卷后才允许批改；权限仍限试卷所属教师或有权限的班级老师。

行为列表显示原始记录与“待复核”标记，不自动认定作弊。失焦和页面隐藏按同次离开合并；编辑辅助、输入法、普通复制剪切、右键、浏览器缩放与旧开发者工具探测不再计入待复核次数。新客户端用 page_leave/page_return 与 episode_id 记录离开区间，有效题目停留不含离开时间。

事件上报新增可选 event_id（UUID）。服务器结合学生 ID 生成事件主键并幂等写入，重复批次和并发重试不会重复累计退出全屏次数。旧客户端没有 event_id 时仍兼容，但无法准确去重其重试，请同步更新前后端。历史原始数据保留，仅重新按统一规则计算统计。

全屏退出次数与其他观察信号独立。“累计退出全屏 3 次自动交卷”仍由教师选择；关闭时只要求恢复全屏，到考试截止仍正常收卷。浏览器信号不能证明学生在其他软件或设备中的操作。
