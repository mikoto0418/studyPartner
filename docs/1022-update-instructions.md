# 1022 二面：两道新题增量更新

本包供已经收到三题版完整部署包的电脑使用，不需要重新下载 2 GB 离线镜像。
只在 **2026 年 10 月 22 日 14:50 开考前、尚无学生作答** 时执行。

## 怎么替换

1. 启动 Docker Desktop，使用原来的 `start-offline.bat` 把三题版平台启动一次。
2. 解压本次增量 ZIP。把整个 **1022-update** 文件夹放进原项目目录，目录应为：

   ```text
   studyPartner-client/
     .env.interview
     docker-compose.interview.yml
     start-offline.bat
     1022-images.tar
     1022-update/
       update-1022.bat
       update-1022.ps1
       替换说明.md
       payload/
       ...
   ```

3. 双击 `1022-update/update-1022.bat`。不用手工复制 payload，也不用运行 pip/npm。
   脚本使用电脑上已有的 Docker 镜像完成离线更新，自动备份数据库和被替换的文件。
4. 出现 **SUCCESS: 5 questions, 140 points** 后，刷新教师页面，确认顺序如下：

   | 题号 | 题目 | 分数 |
   |---|---|---|
   | 1 | 回文日期 | 20 |
   | 2 | 红绿蓝 | 20 |
   | 3 | 字符加密 | 20 |
   | 4 | 送外卖 | 40 |
   | 5 | 分糖果 | 40 |

5. 时间仍为 **14:50～15:50**，班级仍为 **1022二面**，强制全屏开启，累计退出自动交卷关闭。
   三位教师和四十位学生账号、已登记姓名、密码保持原样。

之后重启仍双击项目根目录的 `start-offline.bat`。更新标记存在时，它会跳过旧的镜像包导入，
使用已经更新的本地镜像。**不要删除 `.1022-five-question-updated`，不要手工重新导入旧镜像。**

## 改了什么

- 只新增两道题，把原第 2、3 题移动到第 4、5 题，原三题的题面、分值、判题数据及数据库 ID 保留。
- 总分改为 140；初始化数据与说明同步为五题，重复更新不重复添加。
- “红绿蓝”明确未染色与三色叠加均为白色，区间端点包含在内；输出颜色顺序不变。
- “字符加密”每个字符只按原大小写转换一次，不额外输入 n；最大长度为 999999。
- 本次部署的判题输出上限从 64 KiB 调整为 2 MiB，避免长字符串正确输出被截断；
  Nginx 的 API 请求体上限调整为 8 MiB，允许教师保存带大用例的题目。
- 不修改登录、全屏、自动保存、计时、交卷、判分流程；自测输出展示仍沿用原来的长度限制。

## 失败时

- 若提示考试已开始、已有作答、原题/本地文件不同，脚本会拒绝覆盖；保留窗口错误信息交给维护者处理。
- 备份位于原项目的 `update-backups/日期时间/`，包括 `database.dump` 和替换前文件；旧镜像保留为 `before-日期时间` 标签。
- 不要删除数据卷，不要运行 `docker compose down -v`，不要为了重试重建账号。
- 临时失败修复后可以重新运行脚本：数据库更新是一个事务，已完成的五题更新不会再次添加题目。
- 数据库备份恢复会覆盖备份之后的数据，不要在学生开始考试后自行回滚；需要恢复时先停止操作并保留备份。

PDF 为五页，每题一页，包含公开样例和配图，不包含参考解法或隐藏测试数据。
