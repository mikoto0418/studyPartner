## 1. 回文日期（20 分）

将一个合法的公历日期写成八位数字 `YYYYMMDD`。如果该字符串从左往右与从右往左
读完全相同，就称它为回文日期。例如 `20200202` 是回文日期。

给定起始日期和结束日期，请找出这个闭区间内的所有回文日期，按日期从小到大输出。
日期必须真实存在，不能只检查八位数字是否回文。

### 输入格式

一行两个八位数字字符串 `start end`，分别表示起始日期与结束日期。

### 输出格式

每行输出一个符合条件的八位日期。如果没有符合条件的日期，输出一行 `0`。

### 数据范围

- `20000101 ≤ start ≤ end ≤ 20261022`。
- 保证输入日期合法；区间包含起止日期。
- 按公历判断闰年。

### 样例 1

输入：

```text
20000101 20101231
```

输出：

```text
20011002
20100102
```

### 样例 2

输入：

```text
20200101 20211231
```

输出：

```text
20200202
20211202
```

### 样例 3

输入：

```text
20261001 20261022
```

输出：

```text
0
```

## 2. 红绿蓝（20 分）

有 `n` 面墙，从左到右编号为 `1` 到 `n`，初始全部为白色。
恰好进行 3 次染色：依次用红色、绿色、蓝色油漆，对闭区间 `[l_1,r_1]`、`[l_2,r_2]`、`[l_3,r_3]` 内的墙叠加染色。

染色是叠加，不会覆盖之前的油漆。每面墙最终的颜色只由它被涂上的油漆集合决定：

- 未被染色：白色。
- 只有红色、只有绿色、只有蓝色：分别为红、绿、蓝。
- 红色和绿色：黄色；绿色和蓝色：青色；红色和蓝色：品红色。
- 红色、绿色、蓝色都有：白色。

请依次统计红、绿、蓝、黄、青、白、品红这 7 种颜色的墙的数量。
每面墙恰好计入一种最终颜色；白色数量包括未染色的墙和三色叠加的墙。

### 输入格式

第一行一个整数 `n`。
接下来 3 行，每行两个整数 `l r`，依次给出红色、绿色、蓝色的染色区间。两个端点均包含在区间内。

### 输出格式

一行 7 个整数，用一个空格分隔，依次为红、绿、蓝、黄、青、白、品红色墙的数量。
这 7 个数的和应为 `n`。

### 数据范围

- `1 ≤ n < 1000000`。
- 每次染色均满足 `1 ≤ l ≤ r ≤ n`。
- 每份输入只有一组数据，且总是恰好 3 次染色。

### 样例 1：部分重叠与未染色

输入：

```text
10
1 4
3 6
5 8
```

输出：

```text
2 0 2 2 2 2 0
```

说明：1～2 号为红色，3～4 号为黄色，5～6 号为青色，7～8 号为蓝色，9～10 号仍为白色。

### 样例 2：两种白色来源

输入：

```text
5
2 4
2 4
2 4
```

输出：

```text
0 0 0 0 0 5 0
```

说明：2～4 号三色叠加成为白色，1 号和 5 号未被染色，也为白色。

### 样例 3：品红与端点重叠

输入：

```text
8
1 4
6 8
3 6
```

输出：

```text
2 2 1 0 1 0 2
```

说明：3～4 号为品红色，5 号为蓝色，6 号同时被绿色和蓝色染色，最终为青色。

## 3. 字符加密（20 分）

给定一个只包含大小写英文字母的加密字符串 `s`，请按以下规则解密：

- 原字符为小写字母：转换为对应的大写字母，例如 `a → A`、`z → Z`。
- 原字符为大写字母：在大写字母表中循环右移一位，例如 `A → B`、`B → C`、`Y → Z`、`Z → A`。

每个字符只根据转换前的大小写应用一次规则。小写字母变成大写后，不再右移。
字符的先后顺序保持不变，请输出完整的解密结果。

### 输入格式

一行非空字符串 `s`，只包含 `a`～`z` 和 `A`～`Z`，不含空格。
`n` 表示字符串的长度，不需要单独输入 `n`。

### 输出格式

一行字符串，表示解密结果；输出长度与输入长度相同，所有字符均为大写英文字母。

### 数据范围

- `1 ≤ n < 1000000`。
- 每份输入只有一个字符串。

### 样例 1：按原字符转换一次

输入：

```text
aAzZ
```

输出：

```text
ABZA
```

说明：小写 a 变成 A，大写 A 变成 B，小写 z 变成 Z，大写 Z 回绕为 A。

### 样例 2：混合大小写

输入：

```text
HelloWorld
```

输出：

```text
IELLOXORLD
```

### 样例 3：字母表末尾

输入：

```text
xyzXYZ
```

输出：

```text
XYZYZA
```

## 4. 送外卖（40 分）

小明从宿舍楼 **1 楼楼梯口** 出发，需要送完 `n` 个订单。每个订单给出楼层 `a_i`
和三位房间号 `b_i`。宿舍楼**最多有 6 层楼**，每层有 40 个房间，布局相同，只有中间这一处楼梯可以上下楼。

每层的门口位置如下。上下两排属于走廊的两侧，同一列的两个房间相对。
数字是本层房间编号，例如 4 楼编号 19 的房间，其实际门牌为 419。

```text
左端                                              右端
01  03  05  …  17  19  [楼梯口]  21  23  …  37  39
02  04  06  …  18  20  [自习室]  22  24  …  38  40
```

移动规则：

- 上一层或下一层楼需要 30 秒，只能在楼梯口进行。
- 同一侧走廊中，相邻两列门口之间移动需要 3 秒。
- 走到正对面的门口不需要时间。因此 19 号和 20 号门口之间需要 0 秒，
  楼梯口和自习室门口之间也需要 0 秒。
- 楼梯口所在列也是一个门口位置。19/20 号到楼梯口需要 3 秒，
  楼梯口到 21/22 号也需要 3 秒。
- 放下外卖不花时间；同一房间可以有多个订单，一次到达即可全部送完。
- 订单可以自行决定配送顺序。送完全部订单即可结束，**不需要返回起点**。

求送完全部外卖所需的最短时间。

### 输入格式

第一行一个整数 `n`，代表订单数。
第 2 行至第 `n+1` 行（共 `n` 行订单），每行输入两个整数 `a_i b_i`，分别代表楼层和三位房间号。
例如 `4 432` 表示 4 楼的 432 房间。房间号百位等于楼层，后两位为本层房间编号 01～40。
输入顺序不代表配送顺序，数据不保证按楼层或房间排序。

### 输出格式

输出一个整数，表示最短时间，单位为秒。

### 数据范围

- `1 ≤ n ≤ 1000`。
- `1 ≤ a_i ≤ 6`。
- `b_i` 为三位房间号，满足 `100 × a_i + 1 ≤ b_i ≤ 100 × a_i + 40`，保证房间号与楼层一致。
- 允许同一房间出现多个订单。

### 样例 1

输入：

```text
5
3 321
1 101
2 240
1 119
3 320
```

输出：

```text
189
```

说明：在 1 楼先送左侧订单并返回楼梯口，花费 60 秒；上 2 楼花费 30 秒，
送完右端订单并返回花费 60 秒；再上 3 楼花费 30 秒，最后送完左右两侧相邻房间花费 9 秒。
合计 189 秒，最后不必返回楼梯口。

### 样例 2

输入：

```text
4
6 640
2 201
6 601
1 121
```

输出：

```text
306
```

### 样例 3

输入：

```text
4
2 219
1 120
2 219
1 119
```

输出：

```text
39
```

说明：1 楼的两个订单位于相对的房间，2 楼有重复订单，不应重复计算投递时间。

## 5. 分糖果（40 分）

有 `n` 罐糖果从左到右排成一排，第 `i` 罐中有 `a_i` 颗糖。
A 和 B 轮流拿走一罐糖果，A 先手。每次只能拿走当前剩余罐子中最左边或最右边的一罐，
不能跳过自己的回合，直到所有罐子都被拿完。

两人都知道所有罐子的糖果数量，并始终采取使自己最终糖果总数最大的策略。
请判断最终谁获得的糖果更多。

### 输入格式

第一行一个整数 `n`。
第二行 `n` 个整数 `a_1 a_2 … a_n`。

### 输出格式

输出一个大写字母：

- A 的糖果更多，输出 `A`。
- B 的糖果更多，输出 `B`。
- 两人糖果一样多，输出 `F`。

### 数据范围

- `1 ≤ n ≤ 20`。
- `1 ≤ a_i < 1000`，每罐至少有一颗糖，不允许空罐。
- 每份输入只有一组数据。

### 样例 1：只有一罐

输入：

```text
1
5
```

输出：

```text
A
```

### 样例 2：平局

输入：

```text
2
4 4
```

输出：

```text
F
```

### 样例 3：后手获胜

输入：

```text
3
1 9 2
```

输出：

```text
B
```

说明：无论 A 先取哪一端，B 都可以随后拿走中间的 9 颗糖。

### 样例 4：不能只贪心地取较大的一端

输入：

```text
4
8 15 3 7
```

输出：

```text
A
```

说明：A 先拿右端的 7，之后可以拿到 15，最终获得 22 颗糖；B 获得 11 颗糖。

### 样例 5：每罐只有一颗糖

输入：

```text
3
1 1 1
```

输出：

```text
A
```
