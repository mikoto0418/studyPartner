# 答题代码框：缩进和括号补全更新

本补丁安装在已经完成“五题、140 分”增量更新的版本上。可离线安装，不需要 npm、Python 或下载镜像。

## 安装

1. 启动 Docker Desktop，确保原平台能打开；先装“五题版”更新，再装本包。
2. 解压本 ZIP，把整个 **1022-editor-update** 文件夹放入原项目目录，和 `start-offline.bat` 同级。
3. 双击文件夹内的 **update-editor.bat**，等待出现 **SUCCESS**。
4. 学生页面刷新后生效。若页面已有代码，先看到“已保存到服务器”再刷新；建议在开考前安装。
5. 后续仍使用原 `start-offline.bat` 启动，不要手动重新导入旧镜像包。

脚本只短暂重启前端网页服务，不重启后端、判题器或数据库；不改变题目、账号、分数、考试时间和全屏配置。
压缩包内已经包含构建好的前端文件。原镜像和源码备份保留在 `update-backups/editor-日期时间/`，
镜像标签为 `studypartner-1022-frontend:before-editor-日期时间`。遇到错误保留提示，不删除数据库或数据卷。

## 新操作

- **Tab**：插入空格，缩进到下一个 4 空格位置；焦点留在代码框。
- **Shift+Tab**：减少一级缩进。选中多行时，Tab/Shift+Tab 会一起调整这些行。
- **Enter**：沿用当前行缩进；Python 冒号后增加一级缩进；`{}` 等成对括号中间回车会展开为带缩进的代码块。
- **括号与引号**：输入 `(`、`[`、`{`、单引号或双引号，补上对应的另一半，光标停在中间；选中文字后输入可包住选中内容。
- 已补好的右括号或引号，再输入同一个字符会移到其后；在空括号对中退格会一起删除两边。
- 保留 Ctrl+Z 撤销、Ctrl+Y / Ctrl+Shift+Z 重做，以及原有自动保存、断网草稿与刷新恢复。

缩进与补全会记录为正常编辑，不会误记成粘贴违规。原禁止粘贴规则保持有效。
这里只提供编辑辅助，不会自动重排整段代码、修改变量名或给出答案；字符串和注释中的括号不强行补全。
